# MDLithe

**A focused, high-performance Markdown editor for the modern desktop.**

MDLithe is a professional Markdown editor designed for developers, engineers, and technical writers.

### Highlights
- Distraction-free Markdown editing with live preview
- Mathematical formulas, diagrams, and syntax-highlighted code
- Built-in AI assistance with local and cloud model support
- Document export and integrated Git tools
- Local-first design, with offline editing support
